# 在本機對齊與更新字幕

[English](captions.md)

Family Screen 播放 UTF-8 WebVTT 字幕，不會自行配音，也不會把錄音送到 AI 供應商。你可以在本機製作、檢查字幕，再替已上線的媒體換字幕，不必重新上傳音檔或影片。

## 從錄音找出字幕時間

有原文和錄音時，可以用強制對齊（forced alignment）估算每個字詞出現的時間。例如 [stable-ts](https://github.com/jianfch/stable-ts#alignment) 能在 CPU 上使用已下載的 Whisper 模型。套件和模型下載需要網路；模型下載好後，在本機執行不需要 OpenAI 帳號或 API key。速度與準確度要看電腦和錄音內容。

保留原始文字與錄音。逐字稿、字幕、模型結果、雜湊與複核紀錄放在 `private/` 或 repo 外。對齊工具可裝在獨立的 Python 環境，不必加入網站的執行依賴。

如果很多字被擠在同一個時間點，先檢查那一段，再決定是否換大模型。可以依已確認的語音或停頓邊界，把問題切成較短的區間；stable-ts 的 `align_words()` 能限定一段文字的起訖時間。邊界必須來自錄音，不能靠字數均分總時長。檢查切點前後有沒有漏字、重複字、時間倒退，以及字幕是否快到無法閱讀。

如果音檔根本沒念出某句，對齊無法補回聲音。依內容擁有者的選擇，字幕可以跟著實際朗讀，漏句另存私有紀錄；也可以先複核音檔是否需要補音。不要默默刪掉原文，也不要替沒念出的句子捏造時間。漏句紀錄可包含媒體 ID、原文與音檔 SHA-256、原句、原因和核准的處理方式，不放進 Git 或公開 demo。

## 替已上線的媒體換字幕

在既有 `private/manifest.json` 中，設定要更新的已核准項目之 `subtitle_path`。保留媒體 ID、路徑、容量、時長、排序和其他項目。執行這個指令時，原始媒體所在的外接碟可以離線，但指定的 VTT 必須讀得到。

```bash
npm run cli -- captions --ids YOUR-MEDIA-ID --dry-run
npx wrangler login
npm run cli -- captions --ids YOUR-MEDIA-ID
```

加上 `--local` 可更新本機 Wrangler 環境。這個指令必須指定 `--ids`，不接受 `--all` 與 `--limit`。試跑只檢查本機檔案、列出 ID、容量、字幕段數和雜湊，不連線 Cloudflare。

字幕限不含 BOM 的 UTF-8 WebVTT，每份最多 1 MB，使用 `HH:MM:SS.mmm` 時間與純文字字幕，允許 `NOTE` 區塊。指令會拒絕空白、時間倒退、重疊或超出媒體時長的字幕。這些格式檢查不能證明文字確實對上聲音，聲學校時和試聽仍要另外做。

上傳前，指令會核對整批項目都已發布，且媒體物件、容量與時長和本機清單一致。接著只上傳字幕，物件名稱由媒體 ID 和字幕 SHA-256 組成。D1 只更新 `subtitle_key`；若任一項媒體在預檢後改變，該次更新就不會更動整批項目。重新讀取資料確認後，收據才寫入 `private/captions/`。

音檔、影片、封面、章節切點與帳號進度都保留。舊字幕物件仍在私有 bucket。中斷或資料更新被拒絕時，可能留下一份尚未使用的私有 VTT；相同字幕重跑會沿用相同物件名稱，不會自動刪除物件。

## 確認播放結果

替換後重新整理已開啟的播放器頁面。檢查未登入的字幕與媒體請求回傳 `401`、登入後字幕內容和 VTT 相符、媒體 Range 請求回傳 `206`，並確認帳號仍接續原來的章節與秒數。字幕、接續播放、鎖屏和耳機控制，要在實際使用的手機或電視上確認；桌面測試不能代表 iPhone 已經正常。
